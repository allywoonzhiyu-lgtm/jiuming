I built a tool to make HPLC calls.

HPLC method development is a loop: run, read the chromatogram, change one thing, run again. It's easy to lose track of why you made each change.

With help from AI, I built an Excel tool that checks each run against the method specs and tells you the next move. It shows what to change, why it's the right lever, what you should see if it works, and what to recheck after any change.
